# Ankit ki Shaadi

A playful interactive wedding invitation with a mystery bride reveal, funny RSVP replies, confetti, and optional baraat beats.

## Preview

Open `index.html` in a modern browser. No installation or build step is required.

## Hosting

Served with GitHub Pages from the root of the main branch. The `.nojekyll` file keeps it as a plain static website.

This is a sibling prank; no actual wedding is announced and no RSVP data is collected.
